# TeachPilot 知识库

本目录用于存放计算机学科教学资料，支持 RAG（检索增强生成）功能。

## 目录结构

```
knowledge-base/
├── README.md                    # 本说明文件
├── python-basics/              # Python 入门基础资料
│   ├── 01-变量与数据类型.md
│   ├── 02-控制结构.md
│   ├── 03-函数与模块.md
│   └── 04-面向对象编程.md
├── data-structures/            # 数据结构资料
│   ├── 数组与链表.md
│   ├── 栈与队列.md
│   ├── 树与图.md
│   └── 排序与查找.md
└── algorithms/                 # 算法资料
    ├── 基础算法.md
    ├── 动态规划.md
    └── 贪心算法.md
```

## 支持的文件格式

- **文本文件**: `.md`, `.txt`, `.rst`
- **文档文件**: `.pdf`, `.docx`, `.pptx`
- **代码文件**: `.py`, `.java`, `.cpp`, `.js`, `.ts`
- **数据文件**: `.csv`, `.json`, `.xml`
- **多媒体**: 图片、视频（需特殊处理）

## 使用方法

1. 将教学资料放入对应子目录
2. 在 TeachPilot 界面中选择知识库
3. 系统会自动进行向量化处理
4. 对话时可通过 `#` 命令引用知识库内容

## 比赛要求对齐

- ✅ 本地知识库 RAG 实现
- ✅ 计算机学科领域限定
- ✅ Python 入门教学演示案例

## 注意事项

- 文件大小限制：100MB
- 建议单个文档不超过 10,000 字
- 敏感信息请勿上传
