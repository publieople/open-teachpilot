# Python 入门：变量与数据类型

## 教学目标

1. 理解 Python 变量的概念和命名规则
2. 掌握 Python 的基本数据类型
3. 能够进行简单的类型转换
4. 学会使用 print() 和 input() 函数

## 知识点清单

### 1. 变量

#### 1.1 什么是变量
变量是存储数据的容器，可以想象成一个带标签的盒子，盒子里面装着数据。

```python
# 变量赋值
name = "小明"
age = 18
height = 1.75
```

#### 1.2 变量命名规则
- 只能包含字母、数字和下划线
- 不能以数字开头
- 不能使用 Python 关键字
- 区分大小写

```python
# 正确的命名
user_name = "张三"
age_2024 = 20
_is_student = True

# 错误的命名
2name = "错误"      # 不能以数字开头
class = "错误"      # 不能使用关键字
```

### 2. 数据类型

#### 2.1 数值类型
```python
# 整数 (int)
age = 18
count = -5

# 浮点数 (float)
height = 1.75
price = 99.99

# 复数 (complex)
z = 3 + 4j
```

#### 2.2 字符串 (str)
```python
name = "Python"
message = 'Hello, World!'
multiline = """这是
多行
字符串"""
```

#### 2.3 布尔类型 (bool)
```python
is_active = True
is_deleted = False
```

#### 2.4 空值 (NoneType)
```python
result = None  # 表示空值或无
```

### 3. 类型转换

```python
# 转换为整数
num_str = "123"
num_int = int(num_str)  # 123

# 转换为浮点数
float_str = "3.14"
float_num = float(float_str)  # 3.14

# 转换为字符串
age = 18
age_str = str(age)  # "18"

# 转换为布尔值
bool_val = bool(1)  # True
```

### 4. 输入输出

```python
# 输出
print("Hello, Python!")
print(f"我的名字是{name}，今年{age}岁")

# 输入
user_input = input("请输入你的名字：")
print(f"你好，{user_input}!")
```

## 常见问题

1. **变量可以重新赋值吗？**
   可以，Python 的变量可以随时重新赋值。

2. **如何查看变量类型？**
   使用 `type()` 函数，如 `type(age)`。

3. **字符串可以用单引号或双引号吗？**
   可以，单引号和双引号效果相同，但需成对使用。
